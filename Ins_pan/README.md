# Админ-панель «Цифровой помощник»

Локальный инструмент (не деплоится на GitHub Pages). Пишет в файлы приложения через whitelist.

## Запуск

```bash
cd Ins_pan
npm start
```

Открыть: http://127.0.0.1:8790

## Возможности

1. **Линия и станции** — участки из `line-sections.json`, лента `stations_path`, карточка станции:
   - пробы тормозов → `spr.json` (`brakes.from_moscow` / `to_moscow`)
   - проход / подсказки / теги / операции (ТО при стоянке ≥ N мин) → `spr.json` → `station_ops`
2. **Сводка тормозов** — таблица всех проб
3. **Регламенты** — папки, загрузка PDF, индексация текста → `app/data/instructions/`

## Важно

Сервер слушает только `127.0.0.1`. Перед записью создаёт `*.bak` рядом с файлом.
