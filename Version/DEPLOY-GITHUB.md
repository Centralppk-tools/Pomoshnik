# Деплой на GitHub Pages

## Что заливать

**Содержимое папки `app/`** — все файлы и подпапки в корень сайта (или в подпапку, например `Pomoshnik/`).

Обязательные файлы:

| Файл / папка | Зачем |
|--------------|--------|
| `index.html` | приложение |
| `sw.js` | Service Worker, кеш |
| `manifest.json` | PWA |
| `js/app-config.js` | ключи API (Yandex, depot, CloudTips) |
| `styles/` | все 9 CSS |
| `assets/` | иконки |
| `data/` | конфиги, release-notes, shift-templates |
| `spr.json`, `trains-local.json` | справочники |

## Шаги

1. Локально: `npm run prepare-deploy` (снимок в `Version/snapshots/`).
2. Скопировать **всё из `app/`** в репозиторий GitHub Pages (заменить старые файлы).
3. Закоммитить и push (или Upload files на github.com).
4. Подождать 1–2 мин, открыть production-URL.

## После заливки (телефон)

1. Удалить старую иконку PWA с домашнего экрана.
2. Safari → Настройки → Данные сайтов → удалить сайт (если был сбой).
3. Открыть сайт → войти → «На экран Домой».
